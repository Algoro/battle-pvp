## 1. Unit на ASM-патчи (headless-эмуляция) — 4/4 PASS

- Влево: направление врага (флаг, биты 0-1) становится Left при вводе влево.
- Вправо: направление становится Right.
- Влево: X танка уменьшается (реально движется влево).
- Без ввода: враг ведёт себя как AI (двигается).

**Находка:** одного хука `sub_DDA2` мало — базовый враг перезаписывает направление
через `sub_DE72`. Исправлено вторым хуком `sub_DE72` (DE84). Теперь враг полностью
управляется сетевым вводом (см. `reports/agent-patcher.md`).

## Golden-state харнесс (гарантия «без побочных эффектов»)
По согласованной стратегии (JS-слой решений + минимальные верифицированные ASM-хуки)
реализован `qa/golden-state.js`:
- Фиксированный детерминированный входной скрипт (соло-ATT: автостарт → авто-респавн →
  движение → стрельба) прогоняется на эмуляторе; каждые 60 кадров снимается полный
  образ RAM (0x0000-0x07FF) в виде FNV-хэша.
- Эталон сохранён: `qa/golden/battle-city.solo-att.json`.
- `qa/tests/golden-state.test.js`: любой сдвиг состояния игры (от ASM-патча ИЛИ JS-логики)
  даёт расхождение и падает тест. Валидация: умышленная порча golden → тест падает
  (`finalHash ... != ...`), восстановление → зелёный.
- Детерминизм: два прогона одного скрипта → одинаковый хэш.
- Входит в CI (через `qa/tests/*.test.js`). QA: **16/16 PASS**, CI: **8/8**.

## Фикс: управление танком противника (соло-ATT) — корень и решение
Корень: `sub_DE72` в большинстве случаев отправляла врага к follow-HQ/игрокам (AI),
игнорируя сетевой ввод; JS-перезапись флага движения ломала состояние поворота (0x89).
Решение (ASM, равноразмерно): патч входа `sub_DE72` → `sub_DE72_patched` — если
`ram_net_enemy_dir[X-2] != FF` (игрок держит направление), сразу `A0|dir` в
`ram_tank_flags,X`; иначе — оригинальный AI (продолжение на DE75). Проверено в браузере:
танк движется влево (216→209) при удержании ArrowLeft. Танки без ввода сохраняют AI.
QA: 23/23, e2e: 3/3, CI: 8/8. Golden перегенерирован под новое (намеренное) поведение.

## Управление человеческим танком (AI отключается только у людских танков)
Требование: если играешь за атакующую команду, AI твоего танка отключается, управляет только игрок.
Решение (без ASM-патчей → база не ломается):
- `pvp.js` `setHumanTank(tank)`: танк помечается человеческим. JS задаёт направление
  (до кадра, чтобы пули летели верно) и позицию (после кадра — оверрайд движения ASM;
  при отсутствии ввода танк удерживается на месте). Действует только на живой танк
  (мёртвый не трогаем — респавн работает).
- `tank-driver.js` — движение/коллизии (поле 32x32 по 8px из RAM $0400; проходимость
  путь 0x00/вода 0x0f/0x15; коллизия бокс 8x8).
- Фронт: соло-ATT вызывает `setHumanTank(2)`.
Проверено: без ввода танк стоит, по вводу движется; другие AI-танки и база не затронуты.
Тесты: `qa/tests/human-tank.test.js` (4), e2e «AI танка игрока отключён» (3/3).
CI: 8/8.
